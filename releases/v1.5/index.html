Tekst v1.5
Stable.

The first stable release of the Tekst programming language. A lightweight C++17 interpreter designed around readable syntax and app-oriented development.

VERSION 1.5.0 STABLE C++17 INTERPRETER

What's included

  • Python-inspired syntax
  • Indentation-based blocks
  • Variables and dynamic values
  • Functions and closures
  • Classes and objects
  • Inheritance and method overrides
  • Lists and dictionaries
  • Exceptions with try / catch / throw
  • Modules and imports
  • File utilities
  • Mathematical operations
  • Built-in REPL

Tooling

Tekst v1.5 includes the tk command-line workflow for creating projects, running programs, installing packages, and working interactively. 

tk init
tk new myapp
tk install package
tk run main.tk
tk repl
tk version

Runtime

Tekst source code is processed through a straightforward interpreter pipeline.

  • Lexer
  • Parser
  • Abstract Syntax Tree
  • Direct AST interpreter

There is no bytecode compiler or virtual machine in the v1.5 runtime.

  • Windows
  • macOS
  • Linux
