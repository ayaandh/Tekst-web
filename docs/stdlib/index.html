Standard Library

Tekst ships native modules for mathematics, randomness, files, time, and operating-system utilities.

Overview

imports.tk
import math
import random
import fs
import time
import os

math

Provides mathematical functions and constants including sqrt, cbrt, pow, abs, floor, ceil, round, trigonometric functions, logarithms, exp, min, max, pi, e, and tau.

math.tk
import math
print(math.sqrt(144))
print(math.pow(2, 8))
print(math.pi)

random

Provides random, randint, randrange, uniform, choice, and seed.

random.tk
import random
print(random.randint(1, 10))
print(random.choice(["a", "b", "c"]))

fs

Provides exists, is_file, is_dir, read, write, append, mkdir, remove, and list.

fs.tk
import fs
fs.write("hello.txt", "Hello from Tekst")
print(fs.read("hello.txt"))
fs.remove("hello.txt")

time

Provides timestamp, now, and sleep.

time.tk
import time
print(time.now())
time.sleep(1)

os

Provides cwd, chdir, and env.

os.tk
import os
print(os.cwd())
