Standard Library

Tekst's native standard library is implemented by the runtime. Each module has its own reference page.

Modules

mathMathematics and constantsrandomRandom values and choicesfsFilesystem operationstimeClock and delay helpersosEnvironment and directoriesjsonJSON parsing and encodingsocketTCP and UDP socketssmtpSMTP clienthttpHTTP server

Importing modules

imports.tk
import math
import random
import fs
import time
import os
import json
import socket
import smtp
import http

Native modules do not require local .tk files. Use the individual reference pages for the functions and runtime behavior provided by each module.
