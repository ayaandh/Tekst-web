Standard library

socket

Native TCP and UDP networking primitives.

Creation

tcp() and udp() create sockets.

TCP

connect, bind, listen, and accept provide connection management. send and recv transfer data. peer returns the remote address and close releases a socket.

UDP

sendto sends a datagram and recvfrom returns a dictionary containing data, host, and port.

Options

timeout(socket, seconds) sets send and receive timeouts.

client.tk
import socket
client = socket.tcp()
socket.connect(client, "127.0.0.1", 45678)
socket.send(client, "hello")
print(socket.recv(client, 1024))
socket.close(client)
