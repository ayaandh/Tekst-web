Standard library

json

Native JSON conversion between Tekst values and JSON text.

Functions

decode and parse parse one JSON string. encode and stringify serialize one value. pretty serializes a value with indentation.

json.tk
import json
data = json.decode("{\"name\":\"Tekst\",\"ok\":true}")
print(data["name"])
print(json.encode(data))
print(json.pretty(data))
