TEKST DOCUMENTATION

Learn Tekst.

Everything you need to understand the language, write programs, use the interpreter, manage projects, and experiment with Tekst.

Introduction

Tekst is a lightweight C++17 interpreter for a simple, app-oriented programming language with Python-inspired syntax and indentation-based blocks.

The language includes functions, classes, collections, exceptions, modules, file utilities, mathematical utilities, packages, a project workflow, and an interactive REPL.

Tekst is actively developed. Syntax and implementation details may change as the interpreter evolves.
main.tk
print("Hello, World!")

Installation

Tekst currently provides a Windows installer containing the Tekst interpreter and the tk command-line tool.

Windows

Download and run the installer. If PATH integration is enabled, the tekst and tk commands can be used directly from a terminal.

terminal
tekst --help
tk help

Building from source

Tekst requires a C++17-compatible compiler. GCC and G++ are supported, with MinGW recommended on Windows.

terminal
g++ -std=c++17 -O2 -o tekst src/main.cpp src/lexer.cpp src/parser.cpp -I.

Logical operators include and, or, not, &&, ||, and !.

Assignment

Assignment operators include =, +=, -=, *=, /=, and %=.

Functions

Normal functions are declared with fn. The def keyword is reserved for methods declared inside classes.

functions.tk
fn greet(name):
    return "Hello " + name

fn add(a, b = 0):
    return a + b

fn total(*values):
    result = 0

    for value in values:
        result += value

    return result

print(greet("World"))
print(add(5, 3))
print(total(1, 2, 3, 4))

Function features

  • Parameters
  • Default arguments
  • Variadic arguments
  • Return values
  • Closures
  • fn declarations
  • def class methods

Classes

Tekst supports classes, constructors, fields, methods, objects, inheritance, and method overriding.

classes.tk
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "animal"

class Dog extends Animal:
    def speak(self):
        return "woof"

pet = Dog("Max")

print(pet.name)
print(pet.speak())

Class methods

Methods declared inside classes use def. Constructors use def __init__. Normal functions declared outside classes use fn.

methods.tk
fn create_name():
    return "Tekst"

class Counter:
    def __init__(self, start = 0):
        self.value = start

    def increment(self, amount = 1):
        self.value += amount
        return self.value

Architecture

Tekst uses a direct AST interpreter pipeline.

1. Lexer

The lexer converts source text into tokens that represent the structure and syntax of the program.

2. Parser

The parser converts the token stream into an abstract syntax tree representing the program.

3. Interpreter

The interpreter evaluates the AST directly at runtime.

4. Runtime and tooling

Runtime components provide values, functions, classes, environments, built-ins, file utilities, errors, modules, packages, debugging, and the REPL.

Tekst does not require a bytecode compiler or virtual machine. The AST is interpreted directly.

Example application

Tekst can combine classes, default arguments, mutation, loops, and string interpolation in a single program.

main.tk
class Counter:
    def __init__(self, start = 0):
        self.value = start

    def increment(self, amount = 1):
        self.value += amount
        return self.value

counter = Counter(10)

for i in range(3):
    print(counter.increment())

name = "Tekst"

print("Running {name}")
