TEKST DOCUMENTATION

Learn Tekst.

Everything you need to understand Tekst, write programs, and experiment with the interpreter.

Introduction

Tekst is a lightweight interpreted programming language designed around readable syntax and simple programming concepts.

The current implementation is built in C++ and processes Tekst source through a lexer, parser, AST, and interpreter.

Tekst is currently experimental. Syntax and behaviour may change as the language and interpreter evolve.
hello.tekst
print("Hello, World!")

Installation

The current interpreter is built from source using a C++17-compatible compiler.

Requirements

  • G++ or another C++17-compatible compiler
  • Git
  • Windows, Linux, or macOS

Build

terminal
g++ -std=c++17 -O2 -o Tekst src/main.cpp src/lexer.cpp src/parser.cpp -I.

Syntax

Tekst uses indentation to define blocks. A colon starts a block and indentation determines where that block ends.

syntax.tekst
if x > 10:
  print("Greater than 10")

The lexer produces explicit INDENT and DEDENT tokens and reports inconsistent indentation as an error.

Comments

Comments are not currently implemented by the lexer. Lines beginning with # are therefore not valid Tekst syntax yet.

Variables

Variables can be created by assigning an expression to a name.

variables.tekst
name = "Tekst"
age = 14
active = true

Declarations

Tekst also supports declarations using a type or class name followed by a variable name.

declarations.tekst
let Type value
Type value

Counter counter = Counter(10)

Types

The interpreter currently represents integer, boolean, string, floating-point, object, and function values.

Numbers

numbers.tekst
x = 42
y = 10 + 5

Numeric literals are currently parsed as integers. Floating-point values can still exist at runtime through float().

Booleans

booleans.tekst
enabled = true
disabled = false

Strings

strings.tekst
language = "Tekst"
print(language)

Type conversion

conversion.tekst
number = int("42")
text = str(42)
flag = bool(1)
decimal = float("3.14")

Operators

Tekst currently supports arithmetic and comparison operators.

Arithmetic

operators.tekst
a = 10 + 5
b = 10 - 5
c = 10 * 5
d = 10 / 5
e = 10 % 3
  • + addition
  • - subtraction
  • * multiplication
  • / division
  • % modulo

Comparison

comparison.tekst
x == 10
x != 5
x < 20
x <= 10
x > 5
x >= 10
The lexer recognises and, or, and not, but the current parser does not implement these operators yet.

Control flow

If statements

if.tekst
x = 10

if x > 15:
  print("Large")
elif x > 5:
  print("Medium")
else:
  print("Small")

While loops

while.tekst
count = 0

while count < 5:
  print(count)
  count = count + 1

For loops

The current interpreter supports iterating over lists.

for.tekst
items = [1, 2, 3, 4]

for item in items:
  print(item)

Functions

Functions can be declared using either def or fn.

functions.tekst
fn greet(name):
  print("Hello, " + name)

greet("Tekst")

Return values

return.tekst
fn add(a, b):
  return a + b

result = add(10, 20)
print(result)
Default parameters are parsed by the current parser but are not currently applied by the interpreter.

Collections

Lists

lists.tekst
numbers = [10, 20, 30]

print(numbers[0])
print(len(numbers))

List indexes begin at zero.

Dictionaries

dictionaries.tekst
config = {
  "host": "localhost",
  "port": 8080
}

print(config["port"])

Dictionary keys must currently be strings.

len()

len() returns the length of a string, list, or dictionary.

Classes

Tekst supports classes, constructors, methods, object fields, and attribute access.

classes.tekst
class Counter:
  def __init__(self, start):
    self.value = start

  def increment():
    self.value = self.value + 1

  def display():
    print(self.value)

counter = Counter(0)
counter.increment()
counter.display()

Attributes

attributes.tekst
counter.value = 100
print(counter.value)
The parser recognises extends, but inheritance is not currently implemented at runtime.

Modules

Tekst can load another .tekst file as a module.

Import a module

main.tekst
import math

print(math.value)

Import a member

main.tekst
from math import add

print(add(2, 3))

Error handling

Runtime exceptions can be handled using try and catch.

errors.tekst
try:
  x = 1 / 0

catch error:
  print("Something went wrong")

Common errors

  • Undefined variables
  • Invalid attribute access
  • List index out of range
  • Missing dictionary keys
  • Division by zero
  • Invalid function or method calls
  • Invalid indentation

Running Tekst

Once the interpreter has been built, pass a Tekst source file to the executable.

terminal
Tekst script.tekst

Debug mode

Debug mode prints lexer tokens and the parsed AST before execution.

terminal
Tekst --debug script.tekst

The short form is also available.

terminal
Tekst -d script.tekst

Help

terminal
Tekst --help

Current limitations

Tekst is still under development. Some features are recognised by the lexer or parser but are not fully implemented by the interpreter.

  • Default function arguments are parsed but not applied.
  • Class inheritance is parsed but not implemented at runtime.
  • and, or, and not are lexed but not parsed as expressions.
  • throw is recognised but is not currently implemented as a statement.
  • Comments are not currently supported.
  • Numeric literals are currently integers.
  • For loops currently require a list.
  • Dictionary keys must be strings.
This documentation describes the current interpreter implementation rather than planned language features.
