01 / The language

Small surface.
Room to grow.

Tekst is designed so the first program is approachable and the language can still support larger programs.

01

Indentation is structure

No piles of braces just to show where a block starts. The shape of the code stays visible.

02

Functions feel direct

Define a function, give it arguments, return a value, and keep moving.

03

Lower-level when needed

Collections, classes, modules, pointers, and compiler tooling are part of the wider language surface.

“

The point isn't fewer features. It's less friction between the idea in your head and the code on the screen.
