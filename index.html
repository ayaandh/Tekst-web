01 / ABOUT

A language made
to stay out of your way.

Tekst is a lightweight C++17 interpreter for a simple, app-oriented programming language. It takes inspiration from Python while keeping its own identity.

The language supports variables, functions, classes, collections, exceptions, modules, file utilities, mathematical operations, packages, and a built-in REPL.

Source code is processed through a lexer, parser, abstract syntax tree, and direct interpreter.

02 / FEATURES

Everything you need.
Nothing you don't.

A compact language doesn't have to be a limited one.

04

Classes & objects

Create constructors, fields, methods, instances, inheritance, and method overrides.

05

Collections

Use lists and dictionaries with indexing, assignment, negative indexes, and slicing.

Error handling

Handle runtime problems with try, catch, and throw while receiving useful diagnostics.

07

Modules

Import project, local, and package modules with import, from, and as.

08

Tooling

Use tk for projects and packages, plus the interactive REPL and debug mode.

class Counter:
    fn init(start = 0):
        self.value = start

    fn increment():
        self.value += 1
        return self.value

counter = Counter(10)

for i in range(3):
    print(counter.increment())
05 / ARCHITECTURE

Source code in.
Execution out.

Tekst uses a direct AST interpreter pipeline with no bytecode compiler or virtual machine.

01 Lexer

Converts Tekst source code into tokens.

02 Parser

Converts tokens into an abstract syntax tree.

03 Interpreter

Evaluates the AST directly at runtime.

06 / TOOLING

A language with
its own workflow.

Tekst includes the tk command-line tool for projects, packages, execution, and interactive development.

Create projects, install packages, manage dependencies, run programs, enter the REPL, and inspect versions and help directly from the terminal.

tk new myapp
